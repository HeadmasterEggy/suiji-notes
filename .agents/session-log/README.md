# Session logs

One file per working session that changed the repo: `YYYY-MM-DD-<topic>.md` (UTC date, a few words of topic),
written in the language of the thread.
Write it before the session ends, and commit it with the session's last PR.

```markdown
# <topic>

- Asked: what the person wanted, in a sentence.
- Done: what changed, with PR numbers.
- Checked: what was tested and how; anything not run is listed as not run.
- Open: what is left, and who it waits on.
- Learned: anything the next session would otherwise have to rediscover.
```
