# 思维导图手机版

- 要求：Joey 在 PR #35 合并时说「手机的也做」。
- 已做：
  - 窄屏（导图宽度 < 560px，竖着拿的手机）所有分支都放在标题右边，变成竖长的导图，转屏或改窗口宽度会重新排。

  - 工具栏按钮不再折行（之前手机上「Expand」会断成两行）。
  - 文件：`public/mindmap.js`、`public/style.css`、`public/i18n.js`，新检查 `scripts/checks/mindmap-phone.mjs`。PR 见本次提交。
