## 第 3 轮

- 编辑器里写列表更顺手（和大多数 Markdown 编辑器一样）：
  - 在列表项后按回车，会自动接上下一个 `- `；有序列表的数字自动加一；待办 `- [x]` 后面接上未勾选的 `- [ ]`。
  - 在空的列表项上按回车，就结束这个列表。
  - Tab / ⇧Tab 把选中的列表行缩进或退回一级。缩进的宽度跟上一级的标记一样宽（`- ` 是 2 格，`1. ` 是 3 格），这样 Markdown 才会认成嵌套列表。
  - 代码块里不触发；中文输入法正在选字时按回车也不触发（keyCode 229 / isComposing）。⌘Z 可以撤销。
- 不是列表的行，Tab 还是原来的行为（跳到下一个控件），不会把键盘困在编辑器里。
- 改动文件：`public/ctxmenu.js`；新增检查 `scripts/checks/editor-lists.mjs`（redgreen 验证：旧代码红、修复后绿）。
- 顺手看到但没改的：文件表里记录的大小和实际内容对不上时，打开文档要等约 8 秒的重试才显示（`readText` 的设计，为了避开存储的旧副本），属于同步逻辑，按规则留给 Joey 决定。
