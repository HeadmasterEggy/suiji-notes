# 思维导图记住上次的状态

- 要求：Joey 说「我想让思维导图打开的时候也是上次的状态」。
- 已做：
  - `public/mindmap.js`：每篇文档（按文件 id）把导图的状态存进 localStorage `suiji:mindmap`：是导图还是正文、缩放、横向位置、页面上下位置、哪些分支被折叠/展开。再次打开（换到别的文档再回来、刷新、重开 App）都按上次的样子恢复。编辑后重画也保持。
  - 分支按「从标题到它的一串文字」的哈希来认，改了别处的内容不影响；只存和默认不同的折叠状态。横向位置存的是导图坐标（相对标题），字体加载后重排或窗口变宽也不会偏。
  - 只保留最近 150 篇的状态。全屏不记（退出全屏本来就回到适应宽度），状态存在本机，Mac 和手机各记各的。
  - 原来内存里的 `chosen`（只在本次打开内记住导图/正文）被这个替换。
  - 新检查 `scripts/checks/mindmap-remembers.mjs`：桌面和手机两种尺寸，折叠两处、放大两次、横竖滚动、把普通文档切成导图，然后换文档再回来、刷新页面再回来，都要一样。
- 测试：新检查 redgreen 旧代码红（折叠、缩放、位置、导图开关都没恢复）、新代码绿；mindmap-view / mindmap-phone / mindmap-latex 检查和 `npm run smoke`（27 项）都通过。手机尺寸下截图看过：重新打开后折叠、108% 缩放和滚动位置都和离开时一样。
- 未完成：没在真 iPhone / Mac App 上手动试过（Mac App 加载线上网站，合并部署后自动生效）。
- 备注：云端跑检查前要先 `npm i`（marked / katex 等从 node_modules 提供），否则所有导图检查都会因资源加载失败报错。
